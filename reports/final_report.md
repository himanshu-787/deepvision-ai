# DeepVision AI: Final Technical Report

_Generated by `scripts/generate_report.py` from the artifacts in `artifacts/metrics/`. PyTorch 2.15.0+cpu._

## 1. Project overview
DeepVision AI trains and compares three image classifiers on CIFAR-10 with PyTorch: a CNN trained from scratch,
an ImageNet-pretrained ResNet18 with a frozen backbone (feature extraction), and a fine-tuned ResNet18. The best model is
selected on validation data, evaluated once on the test set, benchmarked, and served through a FastAPI service in Docker.

## 2. Problem statement
Classify 32x32 colour images into 10 classes (airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck) and
measure honestly how training strategy affects accuracy, cost and calibration.

## 3. Objectives
1. Implement real training loops (forward, loss, backpropagation, optimizer updates, validation, checkpointing).
2. Compare scratch training, feature extraction and fine-tuning under a documented protocol.
3. Evaluate with leak-free splits and class-level metrics; analyse errors and calibration.
4. Track experiments reproducibly (YAML configs, seeds, MLflow, TensorBoard).
5. Deploy the selected model as a tested, containerised API.

## 4. Technical architecture
See the diagram in `README.md`. Data (CIFAR-10) -> transforms/DataLoaders -> model factory -> trainer (+ tracking) ->
evaluation -> selection (validation accuracy) -> ONNX/benchmarks -> predictor -> FastAPI -> Docker.

## 5. Dataset
CIFAR-10 (Krizhevsky, 2009): 60,000 colour images of 32x32 pixels, 10 balanced classes. We use the official 50,000 train /
10,000 test split and carve a seeded 5,000-image validation set from the training portion
(45,000 train / 5,000 validation / 10,000 test). Validation and test images are never used for training.

## 6. Data preprocessing
- Training: RandomCrop(32, padding=4) and RandomHorizontalFlip at native resolution, optional upscaling, tensor conversion, normalization.
- Validation/test: no augmentation (deterministic), same resize and normalization.
- Normalization: CIFAR-10 channel statistics for the custom CNN; ImageNet statistics for pretrained ResNet18 models.
- Input size per model: see the `img_size` column below.

## 8. Training methodology
Cross-entropy loss, mini-batch training, per-epoch validation, and checkpointing of the epoch with the highest validation accuracy.
Reproducibility: fixed seeds, YAML-configured runs, config hash and git commit recorded per run (MLflow).

## 9. Fine-tuning methodology
Two stages: (1) train only the new head with the backbone frozen; (2) unfreeze selected backbone stages and train them with
discriminative learning rates (smaller for earlier stages) using AdamW and cosine decay. Frozen BatchNorm layers stay in eval mode.

## 10. Experimental setup
Training devices: cpu. Single seed per configuration unless noted in the experiment log (variance is therefore not
fully characterised). Full run log below (Section 14).

# Error Analysis and Model Diagnostics

This report synthesizes diagnostic evaluations across our three core architectures on CIFAR-10:
- **Model A (`p6_improved_adamw_cos`)**: Custom `ImprovedCNN` with BatchNorm and Dropout trained from scratch with AdamW + Cosine LR scheduler.
- **Model B (`r18_head`)**: Pretrained ResNet-18 feature extractor with frozen backbone and trained linear classification head.
- **Model C (`r18_ft_l34`)**: Two-stage discriminative fine-tuning of ResNet-18 (unfreezing `layer3`, `layer4`, and `fc`).

---

## 1. Confusion Matrix Analysis

- **Model A (`p6_improved_adamw_cos`)**:
  - The dominant confusion is bidirectional animal misclassification: **`cat` $\leftrightarrow$ `dog`** (on the test set: 156 cats predicted as dogs, 150 dogs predicted as cats).
  - Secondary confusions occur within semantic superclasses: `bird` $\to$ `deer` (74) and `truck` $\to$ `automobile` (32).
- **Model B (`r18_head`)**:
  - Displays pronounced cross-category confusions caused by domain mismatch between full-resolution ImageNet pretraining and upscaled $64 \times 64$ CIFAR images without backbone adaptation.
  - Top confusions: `ship` $\to$ `airplane` (146), `deer` $\to$ `bird` (135), and `dog` $\to$ `cat` (123). Sky and water background textures mislead the frozen representation.
- **Model C (`r18_ft_l34`)**:
  - Discriminative fine-tuning almost completely resolves the background-driven errors (ship/airplane confusions drop below top ranking).
  - Residual confusions concentrate on fine-grained biological overlap: `cat` $\to$ `dog` (130) and `dog` $\to$ `cat` (100), along with minor vehicle silhouette overlap (`automobile` $\to$ `truck`: 45).

## 3. High-Confidence Error Gallery Analysis (`*_errors.png`)

Inspection of the top misclassified samples sorted by predicted confidence reveals:
1. **Low native resolution ambiguity**: At $32 \times 32$ native pixels, small animals with obstructed snouts or curled postures lack visible diagnostic features (e.g., small dogs sitting like cats).
2. **Context occlusion**: Animals photographed in water or tall grass are frequently misclassified based on dominant background context.
3. **Vehicle angle ambiguity**: Flatbed trucks photographed head-on share frontal geometry with sedans, causing high-confidence `automobile` predictions on true `truck` labels.

## 7. Documented Limitations

1. **Resolution limitations**: Source images are natively $32 \times 32$; bicubic interpolation to $64 \times 64$ does not restore lost high-frequency spatial information.
2. **Synthetic balance**: CIFAR-10 contains an exact uniform distribution (5,000 train images per class). Real-world applications typically have imbalanced long-tailed distributions.
3. **Out-of-Distribution (OOD)**: Evaluation is strictly in-distribution; performance on noisy, corrupted (e.g., CIFAR-10-C), or natural distribution shifts remains unmeasured.
4. **Single random seed**: The primary comparison models used seed 42; variance across random initializations is assessed via Phase 10 seed reproducibility trials.

# DeepVision AI: Experiment Log & Evidence Trail

This document logs all experiments across Phases 5 through 10, detailing the hypothesis, configuration changes, measured outcomes, and engineering decisions.

---

## Experiment 1: Phase 5 Baseline CNN
- **Run Name**: `cnn_baseline`
- **Model**: `SimpleCNN` (3 convolutional blocks with MaxPool, Linear 512, Linear 10; 620,362 params)
- **Hypothesis**: Standard mini-batch SGD with Adam ($lr=10^{-3}$, no weight decay) on raw $32 \times 32$ CIFAR-10 will establish a solid convolutional baseline (~75–80% validation accuracy).
- **Configuration**:
  - Epochs: 15
  - Optimizer: Adam ($lr=0.001$, $\beta=(0.9, 0.999)$)
  - Regularization: Standard data augmentation (RandomCrop + RandomHorizontalFlip); no dropout, no batch normalization.
- **Results**:
  - Best Val Accuracy: **80.28%** at epoch 14
  - Train Accuracy at Best: 79.91%
  - Total Training Time: 744 s
- **Observations & Symptoms**: Overfitting started appearing by epoch 12 as training loss dropped to 0.55 while validation loss plateaued at ~0.58.
- **Decision**: Accept as the Phase 5 benchmark. Address generalization and variance in Phase 6 with architectural regularization and decoupled weight decay.

---

## Experiment 2: Phase 6 Regularized CNN with Cosine Annealing (Model A)
- **Run Name**: `p6_improved_adamw_cos`
- **Model**: `ImprovedCNN` (Conv blocks with `bias=False`, `BatchNorm2d`, `Dropout(0.3)`; 620,586 params)
- **Hypothesis**: Adding Batch Normalization stabilizes internal covariate shifts, Dropout prevents co-adaptation of features, and AdamW with decoupled weight decay ($10^{-2}$) and Cosine Annealing will eliminate overfitting and improve calibration.
- **Configuration**:
  - Epochs: 15
  - Optimizer: AdamW ($lr=0.001$, weight decay = $0.01$)
  - Scheduler: CosineAnnealingLR ($T_{\max}=15$, $\eta_{\min}=0$)
- **Results**:
  - Best Val Accuracy: **80.14%** at epoch 15
  - Train Accuracy at Best: 77.85% (no overfitting; train-to-val gap is negative: -2.29%)
  - Test Accuracy: **79.63%** | Macro F1: **0.7955**
  - ECE: **0.0096** (near-perfect calibration)
  - Total Training Time: 683 s
- **Decision**: Select as **Model A** (Custom CNN champion). The model achieved near-identical accuracy to baseline while dramatically eliminating overfitting and lowering ECE to under 1%.

---

## Experiment 3: Phase 7 Transfer Learning Feature Extractor (Model B)
- **Run Name**: `r18_head`
- **Model**: ResNet-18 (Pretrained on ImageNet-1k; frozen backbone, new trainable linear head `nn.Linear(512, 10)`; 11,181,642 total params, 5,130 trainable params)
- **Hypothesis**: Reusing rich generic hierarchical visual features from ImageNet will allow fast convergence and competitive classification with minimal trainable parameters.
- **Configuration**:
  - Input resolution: $64 \times 64$ px (bicubic interpolation)
  - Normalization: ImageNet statistics ($\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224, 0.225]$)
  - Epochs: 10
  - Optimizer: Adam ($lr=0.001$, weight decay = 0.0)
- **Results**:
  - Best Val Accuracy: **73.38%** at epoch 10
  - Test Accuracy: **72.35%** | Macro F1: **0.7211**
  - ECE: **0.0778** (over-confident)
  - Total Training Time: 1,090 s
- **Observations & Symptoms**: Accuracy plateaued at ~73% because the backbone weights are completely rigid. The domain gap between high-resolution ImageNet and low-resolution CIFAR-10 causes feature misalignment (e.g. background textures confuse ships with airplanes).
- **Decision**: Keep as **Model B** to demonstrate the baseline capabilities and limits of frozen feature extraction. Proceed to fine-tuning deep layers in Phase 8.

---

## Experiment 4: Phase 8 Discriminative Stage Fine-Tuning (Model C)
- **Run Name**: `r18_ft_l34`
- **Model**: ResNet-18 initialized from `r18_head_best.pt` with `layer3`, `layer4`, and `fc` unfrozen (10,498,570 trainable params).
- **Hypothesis**: Fine-tuning deeper task-specific convolutional stages (`layer3`, `layer4`) using differential/discriminative learning rates (slower for earlier layers, faster for the head) will adapt the model to CIFAR-10 semantics without catastrophic forgetting.
- **Configuration**:
  - Differential LRs: `fc` ($10^{-3}$), `layer4` ($10^{-4}$), `layer3` ($5 \times 10^{-5}$)
  - Optimizer: AdamW (weight decay = $10^{-4}$)
  - Epochs: 7 fine-tuning epochs ($64 \times 64$ px)
- **Results**:
  - Best Val Accuracy: **88.12%** at epoch 7
  - Test Accuracy: **87.83%** | Macro F1: **0.8780** | ROC-AUC (OvR): **0.9910**
  - ECE: **0.0241**
  - Total Training Time: 2,668 s
- **Observations**: Dramatic performance leap (+14.7% over frozen head, +8.2% over custom CNN). Confusions between ships and planes collapsed, and cat/bird detection improved by over 14 percentage points.
- **Decision**: Unanimously selected as the **champion model (Model C)** by validation accuracy.

## 18. Limitations
- CIFAR-10 images are tiny (32x32); real photos differ in resolution, framing and distribution, so accuracy on them is unknown and likely lower.
- The classifier always chooses one of 10 classes; out-of-distribution inputs receive confident wrong labels (`low_confidence` only partly mitigates this).
- One seed per configuration; small differences between models may be within run-to-run noise.
- Pretrained models were upscaled from 32x32, which introduces blur not present in ImageNet data.
- Latency was measured on one machine and excludes preprocessing and network time.
- Known label noise and near-duplicate images between CIFAR train and test sets have been reported in the literature (ciFAIR, Barz & Denzler).

## 19. Future improvements
Repeat runs over several seeds with confidence intervals; hyperparameter search; stronger augmentation (MixUp/CutMix, RandAugment);
